# Shop Credit Manager
A Python-based shop credit management system.
## Features
- Add borrowers
- View pending borrowers
- Mark customers as paid
- View paid customers
- Search customers
- Edit customers details
- Delete customers
- Dashboards with pending and collected amounts
- JSON-based data storage

   ## Technologies Used
  - Python
  - JSON

    ##Purpose
    This project was created to practice Python programming and build a simple system for managing customer credit in a shop
